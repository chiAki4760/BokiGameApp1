# 簿記ドリル２本セット
### 異世界転生屋台 × ダークウェブプロトコル

物語を読みながら、簿記の仕訳を楽しく練習できるゲーム感覚のドリルアプリです。
このREADMEには、使い方・カスタマイズ方法・注意事項をまとめています。

---

## 📦 収録内容

| ファイル名 | 世界観 | ステージ構成 |
|---|---|---|
| `isekai_boki.html` | 🏮 異世界転生屋台 〜スキル【複式簿記】で成り上がる〜 | 全5ステージ×10問（計50問） |
| `darkweb_boki.html` | 👾 DARKWEB PROTOCOL // CYBER BOOKKEEPING | 全5レベル×10問（計50問） |

どちらも他のファイルへの依存がない、単体で完結したHTMLファイルです。
インストール不要・アカウント登録不要・インターネット接続も不要です（フォント読み込みを除く）。

---

## 🚀 使い方

1. ダウンロードしたHTMLファイルを、お使いのブラウザ（Chrome、Safariなど）で直接開く
2. 画面上部のステージ／レベルタブから、挑戦したい章を選ぶ（順番の縛りはありません）
3. 表示された物語を読み、取引の内容を読み取る
4. 「借方（Debit）」「貸方（Credit）」それぞれに、勘定科目名と金額を入力する
5. 判定ボタンを押して、正解・不正解を確認する
6. 全問に正解すると、その章の結末が表示されます

間違えた問題は、結果画面から「間違えた問題だけ復習する」でまとめて解き直せます。
