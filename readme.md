## 🚀 使い方

1. 上記のリンクをタップ、またはブラウザに貼り付けて開く
2. 初回は「このページがClaudeに問い合わせることを許可しますか」等の確認が出ることがあります（許可してください）
3. 画面上部のステージ／レベルタブから、挑戦したい章を選ぶ（順番の縛りはありません）
4. 表示された物語を読み、取引の内容を読み取る
5. 「借方（Debit）」「貸方（Credit）」それぞれに、勘定科目名と金額を入力する
6. 判定ボタンを押して、正解・不正解を確認する
7. 全問に正解すると、その章の結末が表示されます

間違えた問題は、結果画面から「間違えた問題だけ復習する」でまとめて解き直せます。

**次回以降について**：同じリンクをブックマークまたはホーム画面に追加しておくと、いつでもすぐに開けて便利です。答えた問題やステージの選択は、ご自身のブラウザ内に自動で保存されます。ブラウザやアプリを閉じたあとも、同じ端末・同じブラウザで開けば、**答えていた問題からそのまま再開**できます（1問目からやり直しにはなりません）。間違えた問題の復習中に閉じた場合は復習の続きから、章をクリアしたあとに閉じた場合は結果画面がそのまま表示されます。

## 💾 進捗のバックアップ・復元

カスタマイズ用の窓（📥）の中にある**「💾 バックアップ」ボタン**を押すと、今の進捗（何問目まで進んだか・正解数など）と、カスタマイズ内容（テーマ・問題データ）をまとめたテキストが表示されます（ブラウザによっては自動でコピーもされます）。このテキストをメモ帳などに保存しておくと、次のような場合に安心です。

- 別の端末・別のブラウザで続きを再開したい場合
- ブラウザの設定変更やサイトデータの消去で、保存内容が消えてしまった場合
- しばらく開かずにいる間に、ブラウザ側の仕組み（例：iPhoneのSafariなど、一定期間サイトを開かないと自動でサイトのデータを消去するブラウザがあります）で内容が消えてしまった場合

復元するときは、保存しておいたテキストをカスタマイズ用の窓に貼り付けて、「取り込む」（ダークウェブプロトコルは「パッチを適用」）ボタンを押してください。

## 🎨 カスタマイズ方法（上級者向け）

画面下部の **「📥 追加の商談記録を取り込む」**（異世界転生屋台）または **「📥 クラスター設定をインポート」**（ダークウェブプロトコル）を開くと、JSONを貼り付ける窓が**1つ**あります。
この窓から、**見た目のテーマ設定**と**ステージの問題データ**の両方を差し替えることができます。

テーマには、配色・タイトル・ロゴ・ボタンの文言・舞い上がる絵文字に加えて、**文字のフォント**も指定できます（フォントは任意です）。フォントを指定しなければ、元のフォント（ダークウェブは端末風、異世界転生屋台はファンタジー風）のままです。

好きな世界観にカスタマイズしたい場合は、以下のプロンプトをChatGPT・Gemini・Claudeなど
お好きなAIチャットに貼り付けてご利用ください。

**反映手順**

1. 上のプロンプトの【　】部分を埋めて、好きなAIチャットに貼り付ける
2. 返ってきた①（テーマ設定）と②（問題データ）を、窓にそのまま貼り付けて、「取り込む」ボタン（ダークウェブプロトコルは「パッチを適用」）を押す。①と②は、続けて1回で貼っても、1つずつ2回に分けて貼っても大丈夫です
3. 反映されると、配色・タイトル・ボタンの文言（フォントを指定した場合はフォントも）と、5ステージ分の問題が切り替わります。タブの名前も、新しい章のタイトルになります

窓は、貼り付けた内容の種類（テーマ／5ステージ分の問題／今開いている章だけの問題／バックアップ）を自動で見分けます。今開いている章だけを差し替えたいときは、その章のタブを開いてから、`[ { "story": ... }, ... ]` の形の配列を貼り付けてください。

新しいテーマや問題を取り込んでも、それまでの進捗が壊れることはありません。テーマの差し替えは進捗に影響せず、問題データを差し替えた章だけ、その章の進捗が1問目からの状態にリセットされます（他の章の進捗はそのまま残ります）。

フォントは、Google Fontsに実在する名前だけが使えます。名前が違っていたり、読み込めなかったりしたときは、元のフォントで表示されます（表示は崩れません）。フォントの読み込みにはインターネット接続が必要です。

テーマだけを元に戻したいときは、窓の下の「テーマだけ初期値に戻す」を押します。問題も含めてすべて元に戻すときは、画面の一番下にある初期化のリンクを使います。

> ⚠️ AIの回答が稀に不完全（金額の記載漏れなど）になることがあります。
> うまく反映されない場合は、「①と②を、指定した形式・ルールを厳守してもう一度出力してください」と
> 伝えて再生成してみてください。
>
> ⚠️ 取り込みでエラーが出たときは、画面に「○ステージ目の○問目」のように場所が表示されます。その内容をAIに伝えて、「その部分を直して出力し直して」と頼むと、早く直せます。
>
> ⚠️ カスタマイズ内容と進捗は、ご自身の端末・ブラウザにのみ保存されます。別の端末で同じリンクを開いた場合は、
> 初期状態（本来の世界観・1問目）から始まります。端末を変えたいときは、上記の「バックアップ」機能をご利用ください。
