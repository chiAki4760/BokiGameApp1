<h2>🚀 使い方</h2>
<ol>
<li>上記のリンクをタップ、またはブラウザに貼り付けて開く</li>
<li>初回は「このページがClaudeに問い合わせることを許可しますか」等の確認が出ることがあります（許可してください）</li>

<li>表示された物語を読み、取引の内容を読み取る</li>
<li>「借方（Debit）」「貸方（Credit）」それぞれに、勘定科目名と金額を入力する</li>

</ol>

<h2>🎨 カスタマイズ方法（上級者向け）</h2>
<p>画面下部の <strong>「📥 追加の商談記録を取り込む」</strong>（異世界転生屋台）または <strong>「📥 クラスター設定をインポート」</strong>（ダークウェブプロトコル）を開くと、JSONを貼り付ける窓が<strong>1つ</strong>あります。
この窓から、<strong>見た目のテーマ設定</strong>と<strong>ステージの問題データ</strong>の両方を差し替えることができます。</p>
<p>テーマには、配色・タイトル・ロゴ・ボタンの文言・舞い上がる絵文字に加えて、<strong>文字のフォント</strong>も指定できます（フォントは任意です）。フォントを指定しなければ、元のフォント（ダークウェブは端末風、異世界転生屋台はファンタジー風）のままです。</p>
<p>好きな世界観にカスタマイズしたい場合は、以下のプロンプトをChatGPT・Gemini・Claudeなど
お好きなAIチャットに貼り付けてご利用ください。</p>

<p><strong>反映手順</strong></p>
<ol>
<li>上のプロンプトの【　】部分を埋めて、好きなAIチャットに貼り付ける</li>
<li>返ってきた①（テーマ設定）と②（問題データ）を、窓にそのまま貼り付けて、「取り込む」ボタン（ダークウェブプロトコルは「パッチを適用」）を押す。①と②は、続けて1回で貼っても、1つずつ2回に分けて貼っても大丈夫です</li>
<li>反映されると、配色・タイトル・ボタンの文言（フォントを指定した場合はフォントも）と、5ステージ分の問題が切り替わります。タブの名前も、新しい章のタイトルになります</li>
</ol>
<p>窓は、貼り付けた内容の種類（テーマ／5ステージ分の問題／今開いている章だけの問題）を自動で見分けます。今開いている章だけを差し替えたいときは、その章のタブを開いてから、<code>[ { "story": ... }, ... ]</code> の形の配列を貼り付けてください。</p>
<p>フォントは、Google Fontsに実在する名前だけが使えます。名前が違っていたり、読み込めなかったりしたときは、元のフォントで表示されます（表示は崩れません）。フォントの読み込みにはインターネット接続が必要です。</p>
<p>テーマだけを元に戻したいときは、窓の下の「テーマだけ初期値に戻す」を押します。問題も含めてすべて元に戻すときは、画面の一番下にある初期化のリンクを使います。</p>
